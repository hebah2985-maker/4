# نقل (Naql) — محقق النقل العلمي

أداة مدعومة بالذكاء الاصطناعي تساعد طالب العلم على التأكد من أن ما نقله من كتاب موجود فعلًا في الكتاب، وفي الصفحة المذكورة، وأن استنتاجه لا يتجاوز ما يقوله النص.

**رابط التجربة:** (يُضاف هنا بعد النشر)

## المبادئ
- لا فتوى ولا ترجيح ولا حكم على صحة المعنى. الأداة تقول: «هذا موجود في ملفك المرفوع، وهذا موضعه».
- مطابقة الاقتباس والفروق والصفحات **حتمية** (خوارزميات نصية). النموذج اللغوي، إن فُعّل، يُستخدم فقط لصياغة الجواب والحكم على الاستنتاج، وكل مقتبس في مخرجاته يُفحص آليًا أمام نص المصدر.
- كل زائر له مساحة خاصة به، ويمكنه حذف بياناته بزر واحد.

## ما الذي تفعله؟
1. **المصدر:** ارفع PDF (نصي أو مصوّر) أو صورة صفحة. يُستخرج النص (OCR عند الحاجة) وتُفهرس الصفحات.
2. **التحقق من نقل:** الصق اقتباسك والصفحة التي ذكرتها. ترى: الحكم، ونسبة التطابق، والفروق كلمة بكلمة، وهل الصفحة صحيحة، وصورة الصفحة.
3. **سؤال وجواب:** سؤال من المصدر مع الصفحة والنص، أو امتناع صريح إن لم يوجد دليل.
4. **الخصوصية:** حدود الأداة وسياسة البيانات.

## التشغيل على جهازك
```bash
pip install -r requirements.txt
# يلزم برنامج Tesseract مع اللغة العربية (ara) للكتب المصورة
streamlit run app/main.py
```

## النشر (Streamlit Community Cloud)
- ملف التطبيق الرئيسي: `app/main.py`
- الملف `packages.txt` يثبّت Tesseract والعربية، و`requirements.txt` يثبّت مكتبات بايثون.
- لتفعيل النموذج اللغوي ضع المتغيرات في **Secrets** لدى المنصة (وليس في الكود): `NAQL_LLM_PROVIDER`, `NAQL_LLM_BASE_URL`, `NAQL_LLM_API_KEY`, `NAQL_LLM_MODEL`. بدونها يعمل التطبيق بالوضع الحتمي (مقتطفات حرفية من المصدر).

## الاختبارات
```bash
pip install pytest ruff
python -m pytest tests/unit -q
python eval/run_eval.py
```

## حدود معروفة
- مصدر واحد في كل عملية تحقق.
- البحث الدلالي الحالي محلي بسيط (تمثيل حروف)، وليس نموذج Embeddings مدربًا.
- لا يتحقق من الآيات والأحاديث مقابل مصاحف أو مجموعات حديثية معتمدة؛ يعاملها نصًا عاديًا من المصدر.
- OCR للكتب التراثية الرديئة قد يخطئ، وتظهر تحذيرات لجودة الصفحات.
