# 0001 — Local n-gram embeddings instead of an external model

Status: accepted
Date: 2026-10-04

Context:
المتطلبات (§16.2) تشترط استرجاعاً هجيناً: FTS5 + Embeddings، لكن نموذج
الـ Embeddings المعتمد «Needs Clarification». القيود: تخزين محلي فقط
(NFR-07)، لا خدمات خارجية إلزامية (NFR-12)، ممنوع قاعدة متجهات خارجية (§2).

Decision:
اعتماد متجهات حتمية محلية: عدّ n-gram (حرفي، n=3) بتجزئة crc32 إلى 512
بُعداً، تطبيع L2، وتشابه cos في NumPy — مخزنة كـ BLOB في جدول chunks.
الواجهة (`index.embed_text`) معزولة بحيث يمكن استبدالها بنموذج حقيقي لاحقاً
دون تغيير المستدعين (NFR-09 روحاً).

Alternatives:
- sentence-transformers محلياً: أدق لغوياً لكنه يضيف اعتمادية ثقيلة ونموذجاً
  يُحمَّل من الشبكة عند أول تشغيل — يخالف روح NFR-12 للـ MVP.
- FAISS/Chroma: ممنوعان دون ADR، وزيادة تعقيد غير مبررة لحجم كتاب واحد.
- FTS5 وحده: يضعف البحث الدلالي مع الألفاظ المختلفة (مبرر §16.2).

Consequences:
- الكود: لا اعتماديات جديدة؛ المتجهات حتمية وقابلة لإعادة الإنتاج.
- الاختبار: يعمل دون شبكة (T4).
- الأثر: الجودة الدلالية أقل من نموذج مدرب؛ يُعاد التقييم على Gold Set
  عند اعتماد نموذج embeddings رسمي (Open Question قائم).
