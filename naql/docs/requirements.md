# متطلبات مشروع نقل (Naql) — MVP v0.1

المصدر الرسمي الكامل: ملف `naql-requirements.pdf` المرفوع من المنتَج (النسخة الأصلية المعتمدة).
هذا الملف فهرس مرجعي سريع بالمعرّفات التي يُشار إليها في الكود والاختبارات.

## الميزات الإلزامية (Must Have)
- **M1** (FR-01..06): رفع PDF (نصي أو مصوّر)، استخراج النص لكل صفحة، OCR عند الحاجة، تخزين الصفحات مع `pdf_page/printed_page/text_raw/text_source/ocr_confidence`، شريط تقدّم، تحذير للصفحات منخفضة الجودة.
- **M2** (FR-04): إزاحة ترقيم الطبعة `printed_page = pdf_page − offset`، افتراضي 0 وقابلة للتعديل.
- **M3** (FR-10..13): التحقق من الاقتباس: مطابقة تامة → تقريبية → حكم EXACT/MINOR_DIFF/ALTERED/SEMANTIC_ONLY/NOT_FOUND/UNRELIABLE_OCR.
- **M4** (FR-14): التحقق من الصفحة المذكورة: PAGE_OK/PAGE_WRONG/PAGE_UNKNOWN.
- **M5** (FR-15): عرض الفروق كلمةً بكلمة (إضافة/حذف/استبدال) بنص مقروء لا بلون وحده.
- **M6** (FR-16): عرض صورة الصفحة مع النص المطابق والسياق المجاور.
- **M7** (FR-20..26): سؤال وجواب من المصدر فقط مع امتناع صريح عند غياب الدليل.
- **M8** (FR-23): فحص آلي لكل نص يولّده النموذج قبل العرض.
- **M9** (FR-06): مؤشرات جودة OCR وتحذير الصفحات منخفضة الجودة.
- **M10**: شاشة حدود واضحة: لا يفتي، يقتصر على الملف المرفوع.
- **M11** (FR-41): حذف المصدر وكل بياناته بزر واحد.

## Should Have
- **S1** (FR-30..33): حكم دعم النص للاستنتاج SUPPORTED/PARTIAL/EXCEEDS_TEXT/NOT_PROVEN_IN_SOURCE/CONTRADICTED.
- **S2**: إدخال عدة عناصر تحقق دفعة واحدة وجدول وتقرير مجمّع.
- **S3**: Highlight كلمات على صورة الصفحة (يحتاج إحداثيات OCR).
- **S4** (FR-43): تصدير تقرير التحقق (Markdown).
- **S5**: كشف «قريب بالمعنى» فقط (Semantic only).

## قواعد المصدر والاقتباس (§17)
- التعيين على نسخة مؤقتة مع خريطة مواضع للأصل (C6/K1): إزالة التشكيل، إزالة التطويل، توحيد الألف والهمزات وى/ي وه/ة، إزالة علامات الترقيم والأقواس والزخارف، توحيد الأرقام، ضغط المسافات.
- قواعد الأحكام وعتباتها موثقة في `naql_core/thresholds.py`.
- كل إجابة/حكم يتضمن إحالة صفحة (PDF وطبعة عند تحديد الإزاحة)، وعرض النص الأصلي بتشكيله أولاً، والتصريح بحدود الحكم.

## غير وظيفية بارزة
- NFR-01: لا يُعرض أي اقتباس دون فحص وجود ناجح.
- NFR-03/09: فحص الاقتباس < 5 ثوانٍ؛ سؤال وجواب < 20 ثانية (هدف مقترح).
- NFR-05: واجهة عربية RTL كاملة. NFR-06: تعمل على شاشة الجوال.
- NFR-07: تخزين محلي فقط، حذف عند الطلب. NFR-09: قابلية استبدال مزود LLM بواجهة واحدة.
- NFR-12: تشغيل بأمر واحد دون Docker ودون خدمات خارجية إلزامية.

## قصص المستخدم
US-01..US-10 كما في الوثيقة الأصلية (رفع مصور، لصق اقتباس، عرض فروق، تحقق صفحة، سؤال وجواب، حكم استنتاج [Should]، فهم OCR، دفعة عناصر [Should]، حذف بيانات، حدود الأداة).

## حالات الاختبار
TC-01..TC-21 كما في الوثيقة الأصلية (جواب صحيح/امتناع، EXACT/MINOR_DIFF/ALTERED، صفحة خاطئة، NOT_PROVEN_IN_SOURCE، EXCEEDS_TEXT، SUPPORTED، CONTRADICTED، UNRELIABLE_OCR، مصور يحتاج OCR، اقتباس عبر صفحتين، تكرار مواضع، اقتباس قصير، فتوى مرفوضة، خطأ LLM مؤقت).

## مقاييس النجاح
MT-01..MT-10 كما في الوثيقة الأصلية؛ يبقى **MT-03 وMT-04 = 100%** ولا يتراجعان دون سبب موثق.
